# Mi Primer Robot

Sitio web informativo y educativo del programa **Mi Primer Robot**, diseñado para presentar la iniciativa, sus recursos pedagógicos (como las guías y videos de *Otto*), el enfoque del proyecto y el portafolio de actividades en colaboración con instituciones como **La Fábrica**, **Renca** e **Innova**.

## Características Principales

* **Página de Inicio (`index.html`):** Estructura web estática y responsiva que presenta banners promocionales, información sobre el enfoque educativo y galerías visuales del programa.
* **Recursos Educativos y Portafolio:** Acceso directo al portafolio descargable en formato PDF (`portafoli- mi-primer-robot-nov.pdf`) y material multimedia de apoyo (guías y videos de *Otto*).
* **Diseño Visual Personalizado:** Hoja de estilos dedicada (`styles/style.css`) con iconografía propia, adaptabilidad móvil (menú responsivo) y recursos gráficos optimizados.

## Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3.
* **Recursos Multimedia:** Imágenes en formatos PNG, JPG y SVG; documentos en PDF.
